# 제노봇 진화 시뮬레이터

유전 알고리즘으로 제노봇(Xenobot)의 형태가 세대를 거듭하며 진화하는 과정을 브라우저에서 시뮬레이션합니다.

- 단일 HTML 파일 (`index.html`), 움직임 효과에 [anime.js](https://animejs.com) v3 (CDN) 사용
- anime.js를 불러오지 못하거나 “동작 줄이기” 설정이면 움직임 없이 그대로 동작
- 흰색 대시보드형 디자인 (상단 조작 막대 · 결과 줄 · 카드 격자)
- 모바일 화면 대응

## 로컬에서 실행

`index.html`을 브라우저로 열면 바로 동작합니다.

간단한 로컬 서버로 띄우려면:

```bash
npx serve .
```

## 배포

Vercel에 정적 사이트로 배포됩니다. `main` 브랜치에 푸시하면 자동으로 재배포됩니다.
